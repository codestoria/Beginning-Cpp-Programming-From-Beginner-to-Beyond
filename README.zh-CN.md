## 📖 关于本仓库

本仓库整理自 Udemy 课程 *Beginning C++ Programming - From Beginner to Beyond* 的学习代码与笔记，涵盖 C++ 基础语法、流程控制、函数、数组与 `vector`、指针与引用、面向对象编程、继承与多态、STL、模板、异常处理、文件 I/O 以及现代 C++ 特性。

仓库内各章节将**概念笔记**与**可运行代码**配对组织，方便后续回顾核心机制、语言细节边界与练习题。

## 🛠️ 编译与运行

使用现代 C++ 编译器（例如 `g++` 或 `clang++`）编译任意 `.cpp` 文件：

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o main
./main
```
